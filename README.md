# สมุดดูแลสวนองุ่น

เว็บแอปสำหรับบันทึกการดูแลองุ่นรายวัน พร้อมคำแนะนำตามสภาพต้น ใช้งานได้ดีบนมือถือโดยเปิดผ่านเบราว์เซอร์

## นำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ใน repository เปิด **Settings → Pages**
3. ตั้งค่า Source เป็น **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/dist`
4. เปิดลิงก์ที่ GitHub แสดงบนมือถือ แล้วเลือก “เพิ่มไปยังหน้าจอโฮม” หากต้องการใช้เหมือนแอป

## ข้อมูล

รายการดูแลจะเก็บในเบราว์เซอร์ของอุปกรณ์นั้น ใช้ปุ่ม “ส่งออกข้อมูล” เพื่อเก็บสำรอง และ “นำเข้าข้อมูล” เมื่อต้องการย้ายข้อมูลไปอีกเครื่อง

หากต้องการให้ข้อมูลเดียวกันซิงก์บนมือถือและคอมพิวเตอร์ ต้องเชื่อมต่อฐานข้อมูล/บัญชีผู้ใช้เพิ่มในขั้นถัดไป
